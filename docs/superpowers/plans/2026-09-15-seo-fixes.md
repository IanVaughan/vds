**Architecture:** Keep React, Vite and Netlify. Render existing routes to HTML at build time with React's server renderer; hydrate those pages in the browser. React owns page metadata. Use the non-www domain throughout and serve a static 404 for unknown routes.

**Tech stack:** React 19, React Router 7, Vite 8, Node test runner, Netlify static hosting.
